# Fahrizal Yakin

Personal portfolio and journal focused on design, software development, and data exploration.

Live site: https://fahrizalyakin.pages.dev

## Stack

- Astro
- Tailwind CSS
- TypeScript
- Astro Content Collections
- Cloudflare Pages
- GitHub
- Lucide Icons
- Fontsource Variable Fonts

## Pages

- Home
- Work
- Journal
- Playground
- About

## Features

- Responsive layout
- Dark mode
- Content Collections for projects and articles
- Dynamic Work and Journal pages
- RSS feed
- XML sitemap
- Open Graph metadata
- JSON-LD structured data
- Custom 404 page
- Keyboard navigation and accessibility support
- Automated deployment through Cloudflare Pages
